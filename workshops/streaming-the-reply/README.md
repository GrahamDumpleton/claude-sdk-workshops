# Stream the reply as it is written

Find out how to show an answer while the model is still producing it.
Time a reply that arrives all at once, turn on partial messages and
count the events one reply is made of, print the text piece by piece
as it is written, and compare the pieces with the complete message
that follows them.

Fifteen minutes, in a notebook. The workshop makes four small runs on
the smallest model, under the Claude login of the machine it runs on.
