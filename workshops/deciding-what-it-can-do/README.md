# Decide what the agent can do

Find out how an agent's tools are given, approved and withheld. Give
an agent a tool that writes a file and watch the call be refused, then
allow it by name, allow it with a permission mode, and take the tool
away again, reading from each result what was asked for, what was
denied and what was written.

Twenty minutes, in a notebook. The workshop makes five small runs on
the smallest model, under the Claude login of the machine it runs on.
The agent writes one file, inside the workshop's own workspace.
