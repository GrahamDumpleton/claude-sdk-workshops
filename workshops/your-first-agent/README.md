# Run your first agent

Find out what an AI agent is by running one with the Claude Agent SDK.
Send a prompt with `query()` and take apart the messages that come
back, ask a question the model cannot answer on its own, then give the
agent one tool and watch it read a file to get the answer.

Fifteen minutes, in a notebook. The workshop makes four small runs on
the smallest model, under the Claude login of the machine it runs on.
