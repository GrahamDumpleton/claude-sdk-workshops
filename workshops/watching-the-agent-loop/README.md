# Watch the agent loop

Slow an agent's run down until each step can be seen. Ask a question
that takes several tool calls, then take the run apart: what a request
from the model is, who carries it out, how the result gets back to the
model, and why every request is larger than the one before.

Fifteen minutes, in a notebook. The workshop makes two runs on the
smallest model, one of them of several turns, under the Claude login
of the machine it runs on.
