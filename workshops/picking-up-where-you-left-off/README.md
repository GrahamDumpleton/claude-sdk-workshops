# Pick up where you left off

Find out where a conversation goes when the program that held it ends.
List the sessions the SDK keeps on disk and read one back, resume it
from a new run that shares nothing with the first, fork it to try
another way forward without changing the original, and delete what you
made.

Fifteen minutes, in a notebook. The workshop makes four very small
runs on the smallest model, under the Claude login of the machine it
runs on.
