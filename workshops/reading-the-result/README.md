# Read what a run cost

Open the message that ends every agent run. Read how the run ended and
how much work it was, what the token counts mean, what the dollar
figure is and is not on a subscription, and what comes back when a run
is stopped by its turn limit before it finishes.

Fifteen minutes, in a notebook. The workshop makes three small runs on
the smallest model, under the Claude login of the machine it runs on.
