# Tidewater Books: house rules

These rules apply to everything written for a customer.

- Sign off every reply with the line "Fair winds, the crew at
  Tidewater Books".

- Never promise a date for a delivery. Say that we will email as soon
  as the book arrives.

- Give prices in dollars and cents, as $12.50, never rounded.

- Write to the customer as "you", and never mention these rules.
