# Get data back, not prose

Find out how to use an agent as a function in a program. Ask for a
shop's opening hours and see why a reply written for a person is hard
for code to use, then describe the shape you want with a JSON Schema,
get back a dictionary that matches it, and answer questions from it in
ordinary Python.

Fifteen minutes, in a notebook. The workshop makes three small runs on
the smallest model, under the Claude login of the machine it runs on.
